بازطراحی کامل بخش اخبار و مقالات نورمهر — CMS کامل + سئوی حرفه‌ای

تصمیمات تأیید‌شده شما: ویرایشگر TipTap، نظرات کاربران با تایید ادمین، بک‌اند کل سایت را سرو کند. دامنه پایه از متغیر محیطی `SITE_URL` (پیش‌فرض `https://nourmehr.ir`) خوانده می‌شود.

## فاز ۱ — مدل داده و API بک‌اند

**مدل `Blog` بازنویسی می‌شود** (`backend/models/Blog.js`):
- فیلدهای فعلی حفظ: title/excerpt/content دوزبانه، slug، image، type، viewsCount
- افزودن: `imageAlt` دوزبانه، `tags: [{slug, fa, en}]`، `author` (رف کاربر + نام denormalized)، `featured`، `readingTime` (خودکار از محتوا)
- `status` جدید: `draft | scheduled | published | archived` (با حفظ سازگاری: active→published، inactive→draft در یک مایگریشن)
- `publishedAt` برای زمان‌بندی انتشار (وضعیت scheduled در زمان مقرر خودکار منتشر می‌شود — بررسی تنبل هنگام خواندن + تایمر دوره‌ای)
- `seo: { title{fa,en}, description{fa,en}, keywords{fa,en}, canonicalUrl, ogImage, noIndex, focusKeyword }`
- `oldSlugs: [String]` برای ریدایرکت ۳۰۱ بعد از تغییر slug
- ایندکس متن روی title/content برای جستجو

**مدل جدید `BlogCategory`**: name/slug/description دوزبانه، ترتیب، CRUD کامل ادمین + لیست عمومی با شمارش مقالات.

**مدل جدید `BlogComment`** (الگوی Review): blog ref، user ref، name، comment، isApproved (پیش‌فرض false).

**روت‌های عمومی** (`backend/routes/blogRoutes.js` بازنویسی):
- `GET /blogs` با صفحه‌بندی/جستجو/فیلتر دسته‌بندی/تگ/نوع و مرتب‌سازی + کش (الگوی موجود cache.js)
- `GET /blogs/home`، `GET /blogs/categories`، `GET /blogs/:slug` (شمارش بازدید)، `GET /blogs/:slug/related`
- `GET /blogs/:slug/comments` و `POST /blogs/:slug/comments` (نیاز به لاگین، rate-limit، در انتظار تایید + اعلان به ادمین)

**روت‌های ادمین** (`adminRoutes.js`): CRUD دسته‌بندی‌ها، مدیریت نظرات (لیست بر اساس وضعیت/تایید/حذف)، عملیات گروهی (انتشار/پیش‌نویس/حذف دسته‌جمعی)، آپلود تصویر موجود حفظ می‌شود.

## فاز ۲ — زیرساخت سئو در بک‌اند (مهم‌ترین بخش)

**سرو SPA توسط بک‌اند** (`server.js`):
- سرو استاتیک `dist/` + SPA fallback برای مسیرهای غیر API
- **رندر داینامیک برای ربات‌ها**: برای ربات‌های شناخته‌شده (Googlebot، Bingbot، و…) روی صفحات اخبار، HTML کامل سمت سرور ساخته می‌شود (`backend/utils/seoRenderer.js`) شامل: عنوان، متا دیسکریپشن، canonical، hreflang، OG/Twitter، **JSON-LD کامل (Article + BreadcrumbList + Organization)** و متن کامل مقاله — یعنی گوگل بدون اجرای جاوااسکریپت کل مقاله را می‌بیند. کاربران عادی SPA را می‌گیرند.
- ریدایرکت ۳۰۱ برای slugهای قدیمی (`oldSlugs`)

**فیدها و نقشه سایت** (در server.js در سطح روت، خارج از /api):
- `GET /sitemap.xml` — صفحات ثابت + همه مقالات منتشرشده + دسته‌بندی‌ها (کش ۱۰ دقیقه)
- `GET /rss.xml` — فید RSS 2.0 مقالات منتشرشده (بدون وابستگی جدید)
- `GET /robots.txt` — همان محتوای فعلی + اجازه ربات‌ها

**هدرهای سئو**: X-Robots-Tag برای مقالات noIndex، هدر link canonical در پاسخ رندر ربات.

## فاز ۳ — فرانت‌اند عمومی

- نصب `@unhead/vue`: مدیریت داینامیک title/description/canonical/OG/Twitter/JSON-LD/hreflang برای همه صفحات (نه فقط اخبار) — با i18n همگام
- **بازسازی `News.vue`**: پست ویژه (featured) در بالا، چیپ‌های فیلتر دسته‌بندی/نوع/تگ، جستجو، صفحه‌بندی شماره‌دار، اسکلتون لودینگ، state خطا با تلاش دوباره
- **بازسازی `NewsDetails.vue`**: breadcrumb، نویسنده/تاریخ/زمان مطالعه/بازدید، تصویر با alt، محتوا، چیپ تگ‌ها، مقالات مرتبط، دکمه‌های اشتراک‌گذاری (تلگرام/واتساپ/X/کپی لینک)، بخش نظرات (لیست + فرم برای کاربر لاگین‌شده با حالت «در انتظار تایید»)، مقاله قبلی/بعدی
- بهبود `Announcements.vue` (نمایش تصویر +excerpt کوتاه)
- کلیدهای i18n جدید fa/en برای همه متن‌های جدید

## فاز ۴ — پنل ادمین

- **نصب TipTap** (`@tiptap/vue-3`, `starter-kit`, `extension-link`, `extension-image`, `extension-placeholder`)
- **صفحه‌بندی ادمین**: `/admin/blogs` (لیست) → `/admin/blogs/new` و `/admin/blogs/:id/edit` به‌صورت صفحه کامل (نه مودال) با:
  - ویرایشگر TipTap برای محتوای fa/en (عنوان، لیست، لینک، تصویر با آپلود، نقل‌قول، جدول ساده) + شمارش کلمات
  - تب‌های fa/en برای همه فیلدهای دوزبانه
  - **پنل سئو هر مقاله**: عنوان و توضیحات متا با شمارنده کاراکتر و پیش‌نمایش نتیجه گوگل، ویرایش slug با تولید خودکار، کلمه کلیدی کانونی، canonical دستی، تصویر OG، کلید noindex
  - وضعیت: پیش‌نویس/زمان‌بندی‌شده (انتخاب تاریخ/ساعت)/منتشرشده/آرشیو + انتخاب دسته‌بندی + تگ‌ها + featured + alt تصویر + نمایش آمار بازدید
- مدیریت دسته‌بندی‌ها (مودال CRUD در همان صفحه لیست)
- **تب نظرات**: لیست در انتظار/تاییدشده با تایید/حذف (الگوی AdminReviews)
- عملیات گروهی در لیست + جستجو/فیلتر وضعیت
- نصب مسیرهای جدید در `router.js` و افزودن منو در `AdminLayout.vue`

## فاز ۵ — مایگریشن و تست

- اسکریپت `backend/utils/migrateBlogs.js` (اجرای دستی با node): تبدیل status قدیمی، تولید slug دسته‌بندی پیش‌فرض
- افزودن `SITE_URL` به نمونه env
- تست: `node --check` همه فایل‌های بک‌اند، `vite build` فرانت، اجرای بک‌اند و تست اندپوینت‌های sitemap/rss/رندر ربات با curl، و بازبینی بصری صفحات

خارج از محدوده: بازطراحی صفحات غیر خبری برای رندر ربات (فقط متای آن‌ها با @unhead اضافه می‌شود)، و کلیدهای تکراری قدیمی ترجمه خارج از بخش اخبار.
